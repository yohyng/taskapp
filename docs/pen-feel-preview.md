# 書き味の比較用Preview

本番へ統合する前に、Galaxy Z Fold5のChromeで手書きの感触を比較するための専用ページ。

- ブランチ：`codex/pen-feel-preview`
- 入口：`/pen-lab.html`
- 同期や画像転送のクライアントを読み込まず、線はこのページだけで扱う。
- 「現在のペン」「少し粘るペン」を選んで、小さな文字、丸、速い折り返しを比較する。
- 補正は届いた入力ごとに行い、速度に応じて追従を変え、ペン先との距離を表示上3px以内に抑える。固定の待ち時間は足さない。
- 補正済みの点列を保存するので、復元・PNG出力で線を再補正しない。既存の下書きも読める。
- 書き味はこれから描く線へ適用する。前の線は全消去または戻すで取り除いて比べる。
- 描画中の低遅延方式の切替は受け付けない。通常／低遅延の切替時はCanvasを再生成して線を復元する。方式の受付はブラウザーから確認し、実際の遅延改善を保証する表示にはしない。
- 「描画の動作を確認」を開いている間だけrequestAnimationFrameの間隔を測る。これは更新機会の目安であり、実描画FPS・物理的な画面更新・ペンの入力遅延ではない。Fold5の120Hzと書き味は実機で確認する。

## 確認

`npm run test:pen`：専用ページをビルドし、Chromium/WebKitで線の切替・終点・復元・PNG・方式切替を検証する。通常のテストと同時に実行しない。

本番へ統合する前に、Fold5でどちらが好みか、文字の角や払いが欠けないか、低遅延方式にちらつきがないかを確認する。単独ページなので、普段の画面の負荷を含めた比較は統合時に別途必要。


## Fold5での試用後の調整

「もっと強弱があり、敏感で軽やかな方がよい」というフィードバックを受け、「軽やかなペン」を追加。検証版ではこれを初期選択にする。追従の補正を弱め、ペン先との差を1px以内へ抑える。筆圧を初期状態で有効にし、軽い力でも線が出て、強い線との太さの差が大きいカーブを使う。筆圧はチェックを外して無効にもできる。従来の2種類も比較用に残す。

筆圧カーブは線ごとのpressureStyleへ保存する。以前の線の見た目を変えず、復元とPNGでも描画時の強弱を再現する。


## Conceptsの比較画像を受けた調整

「芯のあるペン」を追加して初期選択にした。ごく弱い筆圧でも基準の太さを下回らず、普通の筆圧域では変化を小さくし、強い筆圧だけ少し太くする。追従は軽やかなペンと同じ弱い補正を保つ。前の軽やかな設定も残し、既存の線の描画方式は変更しない。静止画から追従や遅延は判断できないため、太さの調整と実機での書き心地を分けて評価する。


## Conceptsの動画を受けた調整

「なめらかな芯のあるペン」を追加。芯のある筆圧カーブと軽い座標補正を保ち、筆圧の急変だけ短い応答でならす。線分の途中も両端の太さを連続して結び、一定幅の短い線を重ねる段差を減らす。線ごとのflow設定と補正済みの筆圧を保存し、描画・復元・PNGで同じ形を使う。以前の各設定は残す。画面録画では物理的なペン先の遅延は測れないので、120Hzや入力遅延の改善を断定しない。


## 連続輪郭と速度型の比較（1.23.0）

- `/ink-lab.html` を独立した検証入口として追加。以前の `/pen-lab.html` は保持。
- ユーザーと相談した perfect-freehand 1.2.3（MIT）を固定依存として追加。通常アプリには読み込まない。
- 実測の座標・時刻・筆圧を保持し、速度型／実筆圧型／一定幅を同じ輪郭生成で比較する。速度型は時刻差から速度を求め、16msの応答でならす。ライブラリの点間距離による疑似筆圧は使わない。
- 端に独立した膨らみを足さず、輪郭を二次曲線で閉じる。同じ直前の入力を3方式で描き直す。
- 確定線は下のCanvas、入力中の線は上のCanvasに描く。実測点は全て取り込み、上のCanvasの更新はrequestAnimationFrameでまとめる。予測点は使用しない。
- 下書きは `fragments-ink-comparison-v1` に明示保存する。入力のJSONとPNGも端末へ書き出せる。本番の下書き・同期・GASへの経路は持たない。
- 単体テストは速度と入力頻度、実筆圧の保持、一定幅、有限の輪郭、復元時の検証を確認。ブラウザテストはChromium/WebKitで3方式、PNGと復元の一致、入力JSON、操作、実ポインターのキャプチャを確認。
- Fold5上の入力遅延や120Hzを保証するものではない。まず同じ太さでゆっくり／速く書く、輪、角、点、払いを比較し、実機の感触を評価する。


## 速度ペンと鉛筆を並べる（1.24.0）

- 速度型を「Concepts風・速度ペン」と表示し、「Goodnotes風・鉛筆」を追加。どちらも公開仕様を参考にした独自の近似であり、各アプリのアルゴリズムを移植したものではない。
- 鉛筆は幅の変化を小さくし、筆圧を濃淡へ反映。線の輪郭内でグラデーションを描き、固定座標の決定的な紙目マスクを重ねる。傾きの陰影や摩擦感は未対応。
- 描画中と確定後で同じ紙目を使う。各ストロークの範囲だけに一時Canvasを作り、確定線への合成後に保持しない。復元やPNG書き出しで乱数を引き直さない。
- 同じ入力を4種類で再描画。鉛筆の濃淡、筆圧による濃さの増加、復元とPNGの一致をChromium/WebKitで検証する。


## 書き味のスライダー（1.25.0）

太さ1〜40（0.5刻み）、強弱0〜90%、速度由来の強弱の応答4〜64ms、軌跡補正0〜60%を調整する。初期値は1.24.0の太さ10・強弱60%・応答16ms・軌跡15%を保つ。応答は線幅の変化だけに使い、固定の入力待ちを設けない。

設定は `fragments-ink-controls-v1` に保存し、新しい線には設定のコピーを持たせる。既存の線と保存画像は変えない。直前の入力を現在の設定で再描画する見本を別に設ける。基準に戻すボタンで初期値に戻せる。鉛筆では太さと軌跡補正を扱い、濃淡と紙目は従来のまま。


## 太さの移行を分ける（1.25.1）

速度ペンの加速時（細くなる）と減速時（太く戻る）の応答を独立して調整する。初期値は従来どおり16ms/16ms。旧下書きや端末設定の `response` は両方へのフォールバックとして残す。別案12ms/28msは「ゆったり戻る設定を試す」から選べるが、Conceptsの内部定数を示すものではない。

## ゆらぎと厚みの比較（1.25.2）

動画の400％表示を参考に、速度ペンへ「ゆらぎと厚みを残す」設定を追加。座標補正0.03・輪郭補正0.35で小さな手の動きを残し、加速24ms／減速12msと最低疑似筆圧0.3で厚みをつなぐ。ランダムな揺れや端の追加円は使わない。従来の設定へ戻すボタンも保持。Concepts内部の方式を再現した値ではなく、実機比較用の仮説。設定は線ごとに保存するため旧下書きは既定値で復元する。単体7件、Chromium／WebKitのUI24件を確認。

## 局所的なたまり（1.25.4）

66秒の400％動画を参考に、「細さと局所的なたまり」を追加。最低疑似筆圧は従来の0.2へ戻し、減速中の不足速度に応じた小さい補正を12msで受け32msで戻す。座標は変更せず、静止点の補正目標は0。全体を一律に太くせず、追加円や乱数も使わない。前2設定を残して実機比較する。単体8件・Chromium/WebKit28件・対象lintを通過。

## 曲がりの厚みのつながり（1.25.5）

「曲がりとなめらかなたまり」を別設定として追加。直前2区間の方向差を時刻で割り、短い区間のノイズを除外した小さい補正を既存の厚みの余韻に加える。線幅のみ10msでならし、座標は変更しない。旧設定はcurveReturn/widthResponseが0のため従来どおり。長押し直線補正は含めない。単体9件・Chromium/WebKit30件を通過。

## 局所的なたまり・強弱大（1.25.6）

好感触だったINK_LOCAL_RETURNを保持し、強弱0.82・最低疑似筆圧0.14・減速補正0.18の別設定を追加。座標・追従時間・輪郭の補正は基準と同じ。単体10件と対象UI6件（Chromium/WebKit）を通過し、同じ入力で遅い線と速い線の幅の比が広がることと保存復元を確認。

## 局所的なたまり・強弱最大（1.25.7）

強弱大を残し、強弱0.9・最低疑似筆圧0.1・減速補正0.25・加速8ms/減速12msの別設定を追加。位置の補正と輪郭方式は変えず、速い区間の細さと減速時の太さの差を広げる。単体11件・対象UI6件を通過。
