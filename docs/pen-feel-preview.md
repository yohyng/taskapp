# 書き味の比較用Preview

本番へ統合する前に、Galaxy Z Fold5のChromeで手書きの感触を比較するための専用ページ。

- ブランチ：`codex/pen-feel-preview`
- 入口：`/pen-lab.html`
- 同期や画像転送のクライアントを読み込まず、線はこのページだけで扱う。
- 「現在のペン」「少し粘るペン」を選んで、小さな文字、丸、速い折り返しを比較する。
- 補正は届いた入力ごとに行い、速度に応じて追従を変え、ペン先との距離を表示上3px以内に抑える。固定の待ち時間は足さない。
- 補正済みの点列を保存するので、復元・PNG出力で線を再補正しない。既存の下書きも読める。
- 書き味はこれから描く線へ適用する。前の線は全消去または戻すで取り除いて比べる。
- 描画中の低遅延方式の切替は受け付けない。通常／低遅延の切替時はCanvasを再生成して線を復元する。方式の受付はブラウザーから確認し、実際の遅延改善を保証する表示にはしない。
- 「描画の動作を確認」を開いている間だけrequestAnimationFrameの間隔を測る。これは更新機会の目安であり、実描画FPS・物理的な画面更新・ペンの入力遅延ではない。Fold5の120Hzと書き味は実機で確認する。

## 確認

`npm run test:pen`：専用ページをビルドし、Chromium/WebKitで線の切替・終点・復元・PNG・方式切替を検証する。通常のテストと同時に実行しない。

本番へ統合する前に、Fold5でどちらが好みか、文字の角や払いが欠けないか、低遅延方式にちらつきがないかを確認する。単独ページなので、普段の画面の負荷を含めた比較は統合時に別途必要。


## Fold5での試用後の調整

「もっと強弱があり、敏感で軽やかな方がよい」というフィードバックを受け、「軽やかなペン」を追加。検証版ではこれを初期選択にする。追従の補正を弱め、ペン先との差を1px以内へ抑える。筆圧を初期状態で有効にし、軽い力でも線が出て、強い線との太さの差が大きいカーブを使う。筆圧はチェックを外して無効にもできる。従来の2種類も比較用に残す。

筆圧カーブは線ごとのpressureStyleへ保存する。以前の線の見た目を変えず、復元とPNGでも描画時の強弱を再現する。


## Conceptsの比較画像を受けた調整

「芯のあるペン」を追加して初期選択にした。ごく弱い筆圧でも基準の太さを下回らず、普通の筆圧域では変化を小さくし、強い筆圧だけ少し太くする。追従は軽やかなペンと同じ弱い補正を保つ。前の軽やかな設定も残し、既存の線の描画方式は変更しない。静止画から追従や遅延は判断できないため、太さの調整と実機での書き心地を分けて評価する。


## Conceptsの動画を受けた調整

「なめらかな芯のあるペン」を追加。芯のある筆圧カーブと軽い座標補正を保ち、筆圧の急変だけ短い応答でならす。線分の途中も両端の太さを連続して結び、一定幅の短い線を重ねる段差を減らす。線ごとのflow設定と補正済みの筆圧を保存し、描画・復元・PNGで同じ形を使う。以前の各設定は残す。画面録画では物理的なペン先の遅延は測れないので、120Hzや入力遅延の改善を断定しない。
