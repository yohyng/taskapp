# 書くことに集中するモード：Stone の分析と、入れたもの（2026-11-13）

2026-11-13。利用者が Stone（iPad のライティングアプリ）の画面録画を見せて、
「アウトライナーのタイプライターモードをこんな感じにしたい。UI が全部消えて、
書くことに集中できるように」と希望。着手は後日。ここは録画の分析結果。

録画は 2732×2048（iPad Pro 横向き＝CSS で 1366×1024 相当）、67秒。
以下の数値は録画から画素を数えて出したもの。CSS 相当は録画の半分。

## 画面の作り（書いている最中）

|---|---|---|---|
| 本文の左端 | 576 | 288 | **21%** |
| いちばん長い行の右端 | 1438 | 719 | 53% |
| 字の高さ | 38〜45 | 19〜22 | — |
| 行の間隔（行頭から行頭） | 83 | 41 | 字の高さの **約2.0倍** |
| 段落のあいだ | 125〜213 | 62〜106 | 1.5〜2.5行ぶん |
| 書いている行の位置 | y≈1100 | — | 画面の高さの **53%** |

- 背景 `#3A3B41`（58,59,65）。真っ黒ではない、少し青みのある暗い灰
- 字 `#C1C2C6` 前後（191〜195）。**真っ白にしない**。コントラスト比はおよそ 6:1
- 字は明朝寄り。行頭の印・番号・字下げの縦線・枠線は **一切ない**
- 右側は大きく空いたまま。本文は左から 21% に置かれ、行は画面幅の半分ほどで折り返す

## UI の出入り（0.5秒ごとに判定した実測）

| 時間 | 状態 |
|---|---|
| 0.0〜1.0s | 上下の帯が出ている |
| 1.5〜3.5s | iPad の時計だけ（アプリの帯は消えた） |
| **4.0〜20.5s** | **なにも無い（iPad の時計まで消える）** |
| 21〜31s | 打つ・止まるのたびに、時計が出たり消えたり |
| 32〜37s | 時計だけ（手を止めている） |
| 37.5〜53.5s | なにも無い（また書き続けている） |
| 56.5〜60.5s | 上下の帯が出ている（画面に触れた） |

読み取れること。

1. **打ち始めると、アプリの UI はすぐ消える**（1〜2秒以内）
2. **書き続けると、OS の時計やバッテリーまで消える**（アプリの全画面）
3. **手を止めると、まず時計だけ戻る**。アプリの帯は戻らない
4. **画面に触れると、上下の帯が戻る**

## UI が出ているときの形（戻ったとき）

- 上の細い帯 … 左に ✕、中央に見出し（薄い字）、右に ＋ と ⋯
- 下の細い帯 … 左に「検索」、中央に文字数、右に「書式設定」
- 本文の左に、うっすらと行番号。右端に細いスクロールバー
- どちらの帯も背景と同じ色。線で区切らず、字だけが浮かぶ

## 書いている行の位置

打っている行は、画面の高さの **53% あたりに貼り付いたまま**動かない（実測で
y=1095〜1105 を保つ）。改行しても同じ高さに来る。紙のほうが上へ送られる、
いわゆるタイプライター送り。いまのアプリの `view.anchor` は 0.6 なので、
Stone に寄せるなら 0.53 あたり。

## いまの「書くことに集中」との差

すでに `view.immersive` で、打っている間に上の帯・パンくず・行の日付や ⋯ を
薄くし、打っている行以外を薄くする仕掛けはある（0.45秒で引っ込み、指や
マウスを動かすか Esc で戻る）。`view.typewriter` で行の高さを保つ仕掛けもある。
足りないのは次の4点。

1. **消し方が中途半端** … 薄くするだけで、枠・行頭の印・縦線は残る
2. **字組みが一覧のまま** … 行間が詰まり、左右の余白も狭い
3. **アウトラインの見た目が残る** … 点・字下げ・縦線が、文章を書く邪魔をする
4. **枠の中に収まったまま** … 全画面にならない

## 入れたもの（v1.28.0）

⚙ の「フォーカスモード」が、Stone に寄せた形になった。

- **画面いっぱいに開く**（枠の中ではなく、全画面）。Esc で抜ける
- **字組みを Stone の寸法へ**：左の余白 21%（上限 320px）、行間 2.0、
  字は 17px 以上。字の濃さを少し落とす（真っ白にしない）
- **打っている間は、出さない**（薄くするのをやめた）：上の帯・パンくず・
  お気に入り・行頭の印・畳むつまみ・日付・⋯・入れ子の縦線
- **ほかの行を薄くしない**（Stone に合わせた。以前は 25% まで落としていた）
- **打っている行は画面の 53% に留まる**（タイプライター送りを常に効かせる）
- 指やマウスを動かせば、これまで通りすぐ戻る

OS の時計やバッテリーは Web からは消せないので、そこは Stone と違う
（利用者も「消さなくてよい」とのこと）。

## やるときの方針（案・入れる前の検討）

- 既存の `immersive` を育てる（モードを増やさない）。`typewriter` と同時に効かせる
- 消す対象を「薄く」から「出さない」へ：行頭の印・縦線・日付・⋯ を描かない
- 字組みを切り替える：左の余白 21%、行間 2.0、1行は 35〜40 字で折り返す
- 色は `#3A3B41` / `#C1C2C6` を目安に。字を真っ白にしない
- 書いている行は画面の 53% に貼り付ける（`anchor` を 0.53 に）
- その枠だけ全画面にする。Esc で戻る
- 戻すきっかけは Stone と同じく「画面に触れる」。打っている間は戻さない
- 段落の間は1行ぶん多めに空ける

## 決めていないこと

- 打っている段落以外を薄くするか（Stone はしていない。好みを確かめる）
- 下の帯に文字数を出すか（まず何も出さないところから）
- OS の時計まで消すのは Web からはできない。PWA の全画面表示が精一杯

## 気をつけること

- アウトラインの構造（親子・畳み）は壊さない。**見せ方だけ**を変える
- 戻したときに、見ていた場所と編集中の行を見失わせない
- 元の録画は会話にのみ存在する。ここの記述と数値が仕様の控え
