# 書くことに集中するモード：Stone のような手触りへ（未着手）

2026-11-13。利用者が Stone（iPad のライティングアプリ）の画面録画を見せて、
「アウトライナーのタイプライターモードをこんな感じにしたい。UI が全部消えて、
書くことに集中できるように」と希望。着手は後日。

## 録画から読み取れた形

**書いている間（UI がぜんぶ消えている）**
- 画面は一枚の暗い面だけ。枠線・ボタン・行頭の印・字下げの縦線、どれも無い
- OS の時計やバッテリーまで引っ込む（アプリ側の全画面）
- 本文は左から約2割の位置に置かれ、右側は大きく空ける
- 行間はかなり広い（本文の1.8〜2.0倍ほど）。段落の間はさらに空く
- 字は明朝寄り、色は暗い面に対して少し落とした灰色（真っ白ではない）
- 箇条書きの点も番号も出ない。文章がただ並ぶ

**手を止めた／触れたとき（UI が戻る）**
- 上に細い帯：左に ✕、中央に見出し、右に ＋ と ⋯
- 下に細い帯：左に「検索」、中央に文字数、右に「書式設定」
- 本文の左に、うっすらと行番号の点。右端に細いスクロールバー

## いまの「書くことに集中」との差

すでに `view.immersive` で、打っている間に上の帯・パンくず・行の日付や ⋯・
縦線を薄くし、打っている行以外を薄くする仕掛けはある（0.45秒で引っ込み、
指やマウスを動かすか Esc で戻る）。足りないのは次の点。

1. **消し方が中途半端** … 薄くするだけで、枠や行頭の印は残っている
2. **字組みが「一覧」のまま** … 行間が詰まり、左右の余白も狭い
3. **アウトラインの見た目が残る** … 点・字下げ・縦線が、文章を書く邪魔をする
4. **全画面にならない** … 枠（ペイン）の中に収まったまま

## やるときの方針（案）

- 既存の `immersive` を育てる形にする（別モードを増やさない）
- 消す対象を「薄く」から「出さない」へ。行頭の印・縦線・日付・⋯ は描画しない
- 字組みを切り替える：行間 1.9、左の余白 18〜22%、1行の幅は 32〜40 文字程度で止める
- その枠だけ全画面にする（ほかの枠を一時的に隠す）。Esc で戻る
- 下に細い帯で文字数だけ出す案もあるが、まずは何も出さないところから
- 書いている段落以外を薄くするのは、Stone にはない。好みを確かめてから決める

## 気をつけること

- アウトラインの構造（親子・畳み）は壊さない。**見せ方だけ**を変える
- 戻したときに、見ていた場所と編集中の行を見失わせない
- 既存の `typewriter`（書いている行を一定の高さに保つ）と噛み合わせる
- 元の録画は会話にのみ存在する。ここの記述が仕様の控え
