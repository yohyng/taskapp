# 本番の速度ペン（1.23.0）

手書き検証版1.25.7で選ばれた「細さと局所的なたまり・強弱最大」を本体の初期ペンにする。perfect-freehand 1.2.3と検証版の同じINK_EXTREME_RETURNを使う。筆圧ではなく実測の座標・時刻から太さを計算する。

新しい線はbrush: speed-extreme-v1とpointsと同じ長さのtimesを保存。古い線は既存の描画関数を通し、位置・太さ・筆圧を変更しない。このbrushの描画定数は以後固定し、新しい書き味は別のbrush IDを追加する。画像メモは従来どおりPNGで保存するため、端末間の同期形式を変えない。

入力中は現在の線を別キャンバスへ描き、過去の線は確定時だけ更新。拡張した高さは線ごとに保持。従来のペンと筆圧設定も選択可能。太さは1〜20の数値スライダーにした。

検証：sketch/outline-sketchの単体8件と、Chromium/WebKitの手書きUI14件を通過。下書き復元・色・旧筆圧・集約入力・高さ変更・PNG転送失敗と再試行を確認。テスト用通信はService Workerを無効にしてモックする。本番のService Workerには変更なし。

## 描画の遅れ対策（1.23.1）

本番でのガクつき報告を受け、一画の途中のDOM計測を廃止し、開始時の矩形を使う。最初の移動はRAFを待たず表示。長い線のプレビューだけ最大512点（先端128点は密なまま）へ制限し、保存入力と確定/PNGは全点を使う。確定時は先に下のCanvasへ描いてから親の保存処理へ渡す。入力イベントの背面への伝播も止め、描画領域をCSS containで分離。単体6件、全手書きUI14件と最終変更の対象UI6件を通過。Fold実機での体感は別途確認する。

## 表示経路の組み直し（1.23.2）

線がペンを離すまで見えない実機報告を受け、表示用Canvasを一枚に統一。native pointermoveから同じ紙へ描き、前の確定画像は非表示のCanvasへ退避して更新領域だけ戻す。最初の移動は即時、以降はRAFでまとめる。下書きの保存は一画の確定後だけ。入力途中の表示用Canvasの画素と、確定前に保存されないことをChromium/WebKitで検証。実機の遅延改善は端末での確認が必要。

## 四辺への余白と手の接触対策（1.24.0）

紙の四辺の短いバーをドラッグして余白を追加する。横600〜1200、縦210〜1200の範囲で、線の太さと実寸を固定し、上・左の追加分だけ既存の座標を移す。線のpaperWidthとheightを保存し、旧下書きは幅600として読む。PNGも広げた幅で作る。紙の寸法は端末に残し、移動用の手のアイコンをオンにすると指・マウスで表示位置を動かせる。移動は線として保存しない。

ペン入力を受けるとペン専用を自動でオンにして端末へ保存。手が先に触れていても未確定の接触を破棄してペンを優先する。指で描くときはペン専用をオフに戻す。手書き欄のuser-select / -webkit-user-select / -webkit-touch-calloutと、選択・長押し・互換タッチイベントの抑制を併用し、背面へ操作を伝えない。ブラウザーのpen/touch分類を使うため、Apple PencilとSペンの実機での完全な手の接触除去は別途確認する。

検証：単体11件、Chromium/WebKitの手書きUI26件、変更した描画ファイルのeslintとビルドを通過。

## noteボードの追従（1.24.1）

紙へ追加した横幅をnoteボードの最大幅にも加算する。縦は内容に合わせて自然に伸び、画面の上限では既存のスクロールを使う。紙の表示倍率は基準幅から固定し、外枠を広げたり手書きを開き直したりしても線を拡大しない。狭い画面ではボードを画面幅へ収め、紙だけを移動できる。Chromium/WebKitの既存手書き26件と外枠の追従2件を確認（WebKitの高さ確認は画面上限に達しない大きさで実施）。

## ヘッダーから開くsketch（1.25.0）

noteの隣に鉛筆アイコンを追加し、文字欄を持たないSketchBoardを開く。上端にadd memoと閉じる、紙の直上に色・太さ・移動・戻す・全消去をまとめ、種類・ペン専用・筆圧は設定アイコンの中へ畳む。開いたときは閉じるボタンへフォーカスし、ソフトキーボードを出さない。紙は画面の高さに合わせた初期余白を取り、既存の拡張・保存・復元・接触対策を共用する。

閉じても下書きは残り、ヘッダーの印で知らせる。通常のnoteは紙を自動表示せず、sketchの下書きを勝手に本文へ添付しない。既存のnote内の鉛筆操作は任意で紙を開く入口として残す。追加先は従来どおりアウトラインの画像メモ。

検証：Chromium/WebKitの手書きUI計34件を確認。専用画面の下書き復元、保存失敗後の再試行、通常noteとの切り分け、スマホ表示を追加。新コンポーネントとSketchPadのeslint、ビルドとdiffチェックを通過。検証環境の遅延でWebKitの一部が30秒を超えたため、同じビルドの残り8件を120秒上限で再確認した。

## sketchの幅固定と縦スクロール（1.25.1）

sketch専用ボードを画面全体へ広げ、紙全体を表示幅へ収める。左右の拡張バーを外し、紙のスクロールを縦だけに限定。過去に横へ広げた下書きも幅を変更せず全体を収め、画面の幅変更はResizeObserverで追従する。上・下への余白追加、ペン操作、保存は引き続き使える。専用ボードの対象UI8件をChromium/WebKitで確認し、eslint・ビルド・diffチェックを通過。
