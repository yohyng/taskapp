# 実Driveの隔離検証

0.25.0。通常のGAS・画像・控えを変更せず、別のフォルダーと新しいGASプロジェクトへ小さい合成ファイルだけを保存する。
既存GASの控えは成功後に30件へ整理されるため、通常の設定をこの試験へ流用しない。
今回の同期履歴の形式だけを理由に、既存GASを更新する必要はない。

## 準備済みの保存先

11月6日、接続済みDriveのルートに[Task Space 同期検証 2026-11-06](https://drive.google.com/drive/folders/1MV_fndy15Xn4xMBxx8ccVoSF6jgtNAZv)を作成した。
作成後に同じID・名前・空の内容を読み戻して確認した。通常の`storage_image`の中へは作らない。
GAS編集プロジェクトはこの環境のブラウザーでは開けず、未ログインの公開案内ページへ転送された。
デプロイだけはユーザー側で行う。検証コード・設定・貼り付け用GASは先にローカルへ用意する。

## 検証用GASを生成する

```sh
node scripts/prepare-drive-rehearsal.mjs <新規出力フォルダー> <新しく作った検証フォルダーID>
```

通常GASのソースを読み、生成するコピーだけに検証先・ランダムな専用合言葉・検証IDを設定する。
構造が想定と違えば生成を中止し、既存フォルダーへの再生成も拒む。
`検証用GAS.gs`・`manifest.json`・`settings.private.json`を新規フォルダーへ書く。
合言葉入りファイルは`.data`の中だけに置き、Git・チャットへ載せない。生成時にも合言葉を出力しない。

コピーしたGASは控えの整理を実行しない。保存したばかりの不完全ファイルを片付ける従来処理だけは残す。
GETの接続確認には、フォルダーID・検証ID・`retentionEnabled: false`を加える。
別の合言葉・別の保存先・古いGASや整理ありのGASは、クライアントのPOST前に拒否する。
画像と控えの読戻しも加えるが、親フォルダーを辿って検証ルートの配下と確認できるファイルだけを許可する。

## ユーザーが行うデプロイ

1. Apps Scriptで**新しいプロジェクト**を作り、名前を「Task Space 同期検証」にする。
2. 生成済み`検証用GAS.gs`の全文を貼り付けて保存する。フォルダーID・合言葉は設定済みで書き換えない。
3. デプロイ → 新しいデプロイ → ウェブアプリを選び、実行するユーザーを自分、アクセスを全員にする。
4. 新しく得た`/exec`のURLだけを共有する。合言葉や既存の端末設定を共有・変更する必要はない。

GASのデプロイは[Googleのウェブアプリ手順](https://developers.google.com/apps-script/guides/web)を参照。
今回の合言葉はこの検証だけのもので、作るファイルも合成画像と合成JSONに限定する。

## デプロイ後の通し確認

```sh
node scripts/verify-drive-rehearsal.mjs <生成済み出力フォルダー> <新しいGASの/exec URL>
```

通常アプリと同じ`uploadToDrive`・`backupToDrive`を実ブラウザーから使う。
検証先を確認してから1ピクセルの合成PNGを保存し、Drive上の実体のバイト列とSHA-256・ブラウザー表示を確認する。
そのURLと画像幅、日本語・絵文字、タスク・設定、移行原本二件、固定IDの未送信を持つLoro控えを作る。
通常と同じ圧縮・SHA-256照合でGASへ保存し、ファイルIDから読み戻して元のJSONと全バイトを照合する。
ブラウザーの新規IndexedDBへ既存復元関数で取り込み、未送信ID/バイト列・移行原本・本文を確認する。
追記してエンジンを開き直し、同じ控えを再指定しても二重適用されず追記が残ることを確かめる。
ファイルは検証用フォルダーに残す。通常の控えや画像を削除・整理しない。

外部へ送らず復元処理だけを確かめる場合は、次を別に実行する。

```sh
node scripts/verify-drive-rehearsal.mjs .data/local-recovery --local-recovery
```

こちらは`realDrive: false`を返し、実Drive保存の成功に数えない。
ViteとPlaywrightの4185番を使うため、他のローカルブラウザー試験と並行せず、実行中のソースも編集しない。
trace・スクリーンショット・生の例外・認証値は出力しない。失敗時は段階と例外の種類だけを記録する。
